In Chapter 13, the rocket ship fires bullets to destroy the alien spaceships. This is accomplished by using the sprite utility groupcollide(). Search the pygame documentation or other resources on the web and discuss this method does.
According to the official Pygame documentation, groupcollide() is used to find all sprites that collide between two groups. A spirit is an object, such as a bullet, a ship, alien or spaceship. In the alien invention game one sprite group contains the bullets, and another sprite group contains the aliens.  Indeed, when a bullet touches an alien, groupcollide() detects the collision.  For instance, when a bullet hits an alien, the method can remove the bullet, the alien, or both from the game. This mainly depends on whether we used true or false in the method we written. If both are True, then sprit will be removed after they collide. The methods also provide and return information about which sprite collided in the process. As a result, this information can be used to increase the score or create an explosion effect. Overall, the groupcollide() makes collision checking easier because Pygame can check the bullet group and alien group automatically.
